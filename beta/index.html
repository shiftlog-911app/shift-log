Backup & your data

Your log lives only on this phone. Nothing is sent anywhere, and nobody else can see it. If you delete the app or clear Safari's website data, the log is gone, so save a backup now and then. Backups include your notes pages and your own report templates, and private pages stay locked inside the backup. Anything typed into a template's blanks is never in a backup.

Log hands-free with Siri (Safari only)

Siri shortcuts open links in Safari, and Safari keeps its own log apart from the Home Screen icon. Only set this up if you use Shift Log in Safari instead of the icon.

  1. In Shortcuts, make a new shortcut named Shift log.
  2. Add Dictate Text (Stop Listening: After Pause).
  3. Add Change Case → lowercase, then Replace Text: find [^a-z0-9]+ (Regular Expression on), replace with -.
  4. Add Format Date on Current Date, custom format yyyyMMddHHmmss.
  5. Add a URL action: then #log-, the Updated Text, -, the Formatted Date.
  6. Add Open URLs. Put the shortcut on Back Tap or the Action Button.
